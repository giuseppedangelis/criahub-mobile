Expo Router v6 ErrorBoundary API (https://docs.expo.dev/router/error-handling/):
```tsx
// Qualquer arquivo de layout pode exportar um ErrorBoundary nomeado.
// Expo Router passa `{ error: Error; retry: () => void }` automaticamente
// quando um componente filho throws durante render.
export function ErrorBoundary({ error, retry }: { error: Error; retry: () => void }) {
  return <View>...</View>;
}
```

Tema (src/theme/ThemeContext.tsx):
```ts
export function useAppTheme(): {
  mode: "light" | "dark";
  theme: { colors: { background, surface, text, textMuted, primary, border, danger, onPrimary, ... } };
  ...
};
```

Tokens relevantes em `src/theme/tokens.ts`:
- `colors.background` — fundo da tela
- `colors.surface` — card
- `colors.text` / `colors.textMuted` — texto
- `colors.primary` / `colors.onPrimary` — botão de ação
- `colors.danger` — cor de erro/ícone
- `colors.border` — borda de card

Arquivo atual `app/_layout.tsx`:
```tsx
import { Stack } from "expo-router";
import { StatusBar } from "expo-status-bar";
import "react-native-reanimated";
import { AppProviders } from "@/src/contexts/AppProviders";
import { useAppTheme } from "@/src/theme/ThemeContext";

function RootNavigator() { ... }
export default function RootLayout() { ... }
```

**IMPORTANTE:** o componente `ErrorBoundary` exportado por `app/_layout.tsx` NÃO fica envolvido pelo `<AppProviders>` — o Expo Router renderiza o ErrorBoundary como sibling da árvore que quebrou, fora dos providers do layout. Se você chamar `useAppTheme()` dentro do ErrorBoundary do root, ele falha com "ThemeProvider not found" porque o ThemeProvider vive dentro de `AppProviders`. **Solução:** o ErrorBoundary precisa ser um componente auto-suficiente que lê `useColorScheme()` do React Native e aplica os tokens do módulo `src/theme/tokens.ts` diretamente via import.

                   {error?.message ?? String(error)}
                 </Text>
               ) : null}
               <Pressable
                 accessibilityRole="button"
                 accessibilityLabel="Tentar novamente"
                 onPress={retry}
                 style={({ pressed }) => [
                   styles.errorButton,
                   { backgroundColor: c.primary, opacity: pressed ? 0.8 : 1 },
