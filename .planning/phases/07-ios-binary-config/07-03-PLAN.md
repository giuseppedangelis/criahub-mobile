<objective>
Rewrite the four iOS usage description strings in `app.config.ts` to cite the specific screen and flow that triggers each permission (per Apple review guidelines 2.3.8 "clarity" and 2.3.10 "specificity"), AND fully remove `NSMicrophoneUsageDescription` both from `ios.infoPlist` and from the `expo-image-picker` plugin config. The audit in CONTEXT D-06 confirmed zero actual microphone usage: no `expo-av`, no `Audio.Recording`, no `MediaTypeOptions.Videos`, all `ImagePicker.launch*` calls use `mediaTypes: ["images"]` only.

Purpose: Apple rejects generic usage strings in 2026 reviews (CONTEXT D-04). "The CriaHub usa a câmera para registrar fotos de animais, documentos e foto de perfil" is too abstract; "A câmera é acionada apenas quando você toca em 'Adicionar foto' nas telas de Animal, Conta ou Campo" is specific. Simultaneously, declaring `NSMicrophoneUsageDescription` without actual microphone usage is itself a review risk (Apple 5.1.1) and must be removed from BOTH places — infoPlist AND plugin — because the Expo image-picker plugin regenerates the string into infoPlist during prebuild if only one side is edited (CONTEXT D-07).

Output: app.config.ts with four rewritten permission strings and microphone references fully excised; atomic commit; typecheck green.
</objective>
