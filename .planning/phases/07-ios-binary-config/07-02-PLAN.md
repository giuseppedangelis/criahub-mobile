<objective>
Install the `expo-build-properties` Expo config plugin and wire it into `app.config.ts` to pin the iOS deployment target at `"15.1"`. This gives the EAS-generated Xcode project an explicit iOS 15.1 floor (vs. whatever default Expo SDK 54 picks), satisfying IOS-02 and Apple's current minimum supported iOS requirement with room to spare.

Purpose: Without an explicit deployment target, the Podfile generated on EAS workers uses Expo SDK 54 defaults that can drift between builds. Pinning it in repo-tracked config makes the floor deterministic and auditable in `Podfile.lock` post-build.

Output: `expo-build-properties` added to `dependencies`; new entry in the `plugins` array; verified via Expo's config introspection.
</objective>
