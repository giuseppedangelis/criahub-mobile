<objective>
Implementar NOTIF-01: impedir vazamento de notificações locais entre usuários no mesmo device. signOut cancela todos os lembretes agendados; onAuthStateChange detecta troca de usuário (via owner-id persistido em AsyncStorage) e também cancela reminders quando necessário.

Purpose: Eliminar cenário LGPD/privacy em que usuário B recebe lembretes agendados por usuário A (inclusive quando signOut é pulado — refresh token trocado, restore de backup, bug futuro).

Output: `clearAllReminders()` cabeada no signOut + handler de user-mismatch em onAuthStateChange + persistência do owner id. A detecção de mismatch no bootstrap é coberta pelo próprio `onAuthStateChange` via evento `INITIAL_SESSION` (supabase-js v2 emite sempre no mount), então NÃO duplicamos a lógica dentro do `bootstrap()`.
</objective>

**Modificar o callback de `onAuthStateChange` (linhas 114-135)** para user-mismatch detection. Nova versão do callback:

```ts
const { data: authState } = supabase.auth.onAuthStateChange(
  async (_event, nextSession) => {
    if (!mounted) return;

    // NOTIF-01 D-10: detecta troca de usuário no mesmo device ANTES de
    // trocar a state, para não vazar lembretes do usuário anterior.
    // Este handler dispara também em INITIAL_SESSION no mount (supabase-js v2),
    // então cobre tanto o caso de troca em tempo real quanto o bootstrap inicial
    // quando há sessão persistida — sem duplicar a lógica em bootstrap().
    const nextUserId = nextSession?.user?.id ?? null;
    const storedOwnerId = await readOwnerUserId();

    if (nextUserId) {
      if (storedOwnerId !== nextUserId) {
        await clearAllReminders();
        await writeOwnerUserId(nextUserId);
      }
    } else if (storedOwnerId) {
      // Sessão terminou por qualquer via (signOut, refresh-fail, etc.)
      await clearAllReminders();
      await clearOwnerUserId();
    }

    if (!mounted) return;

    setSession(nextSession);
    setUser(nextSession?.user ?? null);

    if (nextSession?.user) {
      try {
        await loadProfile(nextSession.user.id);
      } catch {
        setProfile(null);
        setRole("unknown");
        setHarasId(null);
      }
    } else {
      clearUserState();
    }

    setIsLoading(false);
  }
);
```
