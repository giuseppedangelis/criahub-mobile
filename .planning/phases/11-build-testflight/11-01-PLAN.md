<objective>
Validar — e se necessário regenerar — o ícone principal `./assets/images/icon-criahub.png` para atender aos requisitos estritos do App Store: 1024×1024 pixels exatos, profile sRGB, e sem canal alpha. Apple rejeita automaticamente PNGs com transparência ou profile não-sRGB. Essa task é **pré-requisito do BUILD-06 (primeira production build)** — um ícone inválido reprova no upload para ASC.

Purpose: Garantir que o primeiro production build (BUILD-06) não seja reprovado no upload por footgun de asset (Pitfall 12 — "metadata mismatch" categoria de assets). A validação é determinística via `sips` (CLI nativo macOS) e corrige o problema antes do build, evitando round-trip de 15-25 min.

Output: Ícone validado em disco + registro da saída `sips -g all` no SUMMARY para três-way audit pós-build.

<task type="auto">
  <name>Task 1: Validar e corrigir ícone 1024 sRGB sem alpha (D-01, D-02, D-03)</name>
  <files>assets/images/icon-criahub.png</files>
  <read_first>
    - `assets/images/icon-criahub.png` — arquivo atual (verificar metadata)
    - `app.config.ts:13` — confirmar que o path referenciado é `./assets/images/icon-criahub.png`
  </read_first>
  <action>
    Executar os seguintes passos em ordem, parando e corrigindo quando qualquer critério falhar:

    **Passo 1 — Validar estado atual (D-01):**
    ```bash
    sips -g pixelWidth -g pixelHeight -g hasAlpha -g profile ./assets/images/icon-criahub.png
    ```
    Capturar a saída literal. Critérios de aprovação:
    - `pixelWidth: 1024`
    - `pixelHeight: 1024`
    - `hasAlpha: no`
    - `profile:` deve conter `sRGB` (ex.: `sRGB IEC61966-2.1` ou `Display P3` NÃO — se P3 ou outro wide-gamut, converter para sRGB)

    **Passo 2 — Se `hasAlpha: yes` (D-02):**
    Strip do canal alpha via sips, escrevendo em arquivo temporário e depois movendo sobre o original:
    ```bash
    # sips não tem flag --removeAlpha; caminho padrão é converter via -s format
    sips -s format png -s formatOptions default --deleteColorManagementProperties \
      ./assets/images/icon-criahub.png \
      --out ./assets/images/icon-criahub.tmp.png
    # Re-validar o tmp:
    sips -g hasAlpha ./assets/images/icon-criahub.tmp.png
    # Se ainda yes, usar pipeline alternativo com ImageMagick/macOS built-ins.
    # Abordagem 100% nativa (sem instalar nada): usar sips com flatten em fundo preto
    # (o ícone é full-bleed dark #0d0d0d, então flatten em black é visualmente idêntico).
    # Se sips não resolver, usar o atalho:
    sips -s format png --setProperty hasAlpha false \
      ./assets/images/icon-criahub.png --out ./assets/images/icon-criahub.noalpha.png
    # Se MESMO assim ficar com alpha, escalar para re-exportação via Preview.app:
    #   open -a Preview ./assets/images/icon-criahub.png
    #   Arquivo → Exportar → PNG → desmarcar alpha → salvar como icon-criahub.png
    # Documentar em SUMMARY qual caminho foi usado.
    ```
    Depois mover por cima do original e re-validar Passo 1.

    **Passo 3 — Se `profile` NÃO é sRGB (Display P3, Generic RGB, etc.):**
    ```bash
    # Converter para sRGB (profile Apple-friendly):
    sips --matchTo "/System/Library/ColorSync/Profiles/sRGB Profile.icc" \
      ./assets/images/icon-criahub.png \
      --out ./assets/images/icon-criahub.srgb.png
    mv ./assets/images/icon-criahub.srgb.png ./assets/images/icon-criahub.png
    # Re-validar Passo 1.
    ```

    **Passo 4 — Se `pixelWidth != 1024` OU `pixelHeight != 1024`:**
    **NÃO usar sips resize** (perde qualidade no upscale; no downscale ok mas só se dimensão atual for maior). Regenerar do design source (Figma/Sketch) como PNG 24-bit 1024×1024 full-bleed. Se não houver design source disponível nesta sessão, **STOP** — reportar bloqueador ao usuário (requer asset novo do designer).

    **Passo 5 — NÃO adicionar bordas arredondadas (D-03):**
    Apple aplica a mask iOS automaticamente. O ícone deve ser square full-bleed com design edge-to-edge. Se o ícone atual JÁ tem bordas arredondadas desenhadas, flag como blocker — é regeneração do design source, não correção CLI.

    **Passo 6 — Registrar evidência:**
    Salvar saída completa de `sips -g all ./assets/images/icon-criahub.png` no SUMMARY do plan para rastreabilidade pré-review.
  </action>
